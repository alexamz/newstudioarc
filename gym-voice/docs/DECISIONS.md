# Gym Voice — Decisiones
- 2026-11-15: velocidad de POC sobre infraestructura; sin backend ni nuevos recursos Azure.
- Modos durante y todo al final comparten un modelo de sesión.
- Un dictado nunca se guarda sin confirmación del usuario.
- Repeticiones >40 se marcan como ambiguas y bloquean hasta corregir.
- Uso temporal de una rama aislada en `newstudioarc` (master intacto); CDN pública solo para pruebas con datos ficticios por riesgo de origen compartido.
- Sin duplicar workflows de Azure. Sin commits pequeños: una publicación atómica.
- 2026-11-15: tras fallo real de SpeechRecognition en Safari iPhone, preferir dictado nativo del teclado (sin SDK ni servicios de pago), con botón que enfoca textarea. Mantener Atajos fuera del flujo principal hasta aceptación.
- 2026-11-15: tras aceptación del dictado de teclado, robustecer parser determinista antes de añadir infraestructura. 19 pruebas Node integradas en repo sin workflow ni runner. Preferir alerta/revisión a inventar datos ante dictados incompletos.
- 2026-11-15: el usuario rechazó la calidad semántica de 19 tests sintéticos frente a dictados reales. Cortar inversión en heurísticas/regex. Separar voz->texto de texto->datos estructurados. Priorizar interpretación LLM, catalogación de ejercicios con contexto de rutina e incertidumbre explícita. Nunca inferir datos no dichos. API key solo en backend autenticado.
- 2026-11-15: examinado `quant-research` Azure OpenAI/Foundry `gpt-5-mini`, validación histórica PASS Attempt 013, Managed Identity scope a `quant-val-api`. No modificar Quant ni reutilizar su identidad sin aislamiento y RBAC. Connector de Quant devuelve HTTP 404 actualmente; no prueba estado live. POC temporal admite importación ChatGPT→Gym mediante `#import=` seguro, validado y con confirmación explícita, sin presentar heurísticas como IA.
- 2026-11-15: screenshot of ChatGPT deep link showed basic-parser 'Faltan repeticiones' warning. Prior UI could unintentionally reinterpret imported data. Structured import now has its own review-first view; the basic parser is suppressed while imported data is pending. Confirm-only, no auto-save. Screenshot cannot prove where the fragment was lost/which button was pressed.
- Preserve imported transcript and structured sets on session-mode switch; regression checked using DOM-stub direct JS run, no Azure runtime.
- 2026-11-15: single-user-only product: avoid accounts/roles/user-db. Keep local-only storage for POC and atomic writes, export backup; no cloud sync claim. Do not treat lack of multiuser as authorization to expose Azure OpenAI without abuse protection / cost cap. No added Azure resources until secure minimum path exists.
- 2026-11-15: single-purpose stateless Azure Container App chosen over Static Web Apps Free managed Functions, because these managed Functions do not support Managed Identity. New isolated app with own identity, same origin for UI/API, server-only token, per-process throttling (not global cap), model quota/budget guard to configure. Build code only; no deployment until isolated identity and secure hosting are authorized/configured. Never embed provider credentials in a shared-origin CDN.
